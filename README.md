# TaskFlow - 할 일 관리(To-Do List) 프로그램

PRD 명세를 바탕으로 개발된 반응형 할 일 관리(To-Do List) 웹 애플리케이션입니다.

---

## 🚀 실행 방법

별도의 복잡한 설치 과정 없이 바로 실행할 수 있습니다.

### 방법 1. 브라우저에서 바로 열기 (가장 간단한 방법)
- 프로젝트 폴더 내의 **`index.html`** 파일을 더블 클릭하여 Chrome, Safari, Edge 등의 브라우저로 엽니다.

### 방법 2. Python 로컬 서버로 실행하기
터미널에서 아래 명령어를 실행한 뒤 브라우저에서 `http://localhost:8000`으로 접속합니다:
```bash
python3 -m http.server 8000
```

---

## ✨ 주요 구현 기능

1. **빠른 할 일 등록 (Zero Friction)**
   - 메인 화면 입력창에서 텍스트 입력 후 `Enter` 키로 1초 만에 등록
   - 우선순위(높음/보통/낮음), 마감일(캘린더), 카테고리 퀵 선택 지원

2. **완료된 일 하단 분리 보관 (요청 반영)**
   - 체크박스를 클릭하면 즉시 완료 취소선이 적용되며, 메인 목록 하단의 **'완료된 항목' 전용 섹션**으로 이동합니다.
   - **접기/펼치기 아코디언**을 지원하여 진행 중인 작업에 집중할 수 있습니다.
   - 하단 완료 목록에서 체크를 다시 클릭하면 즉시 **진행 중 목록으로 복귀**합니다.
   - '완료 목록 비우기' 기능으로 완료된 항목을 한 번에 정리할 수 있습니다.

3. **마감일 & D-Day 실시간 계산**
   - 오늘 마감, 내일 마감, D-day, 지연됨(붉은색) 등 시각적 배지 제공

4. **스마트 필터링 및 카테고리 관리**
   - 사이드바: 전체 / 오늘 할 일 / 중요(높은 우선순위) / 사용자 정의 카테고리
   - 메인 탭: 전체 / 진행 중 / 완료됨
   - 검색창 실시간 제목 및 메모 필터링

5. **상세 편집 드로어 (Drawer)**
   - 할 일 카드를 클릭하면 우측에서 슬라이드로 열리는 정밀 편집 창
   - 세부 메모 작성 및 서브 체크리스트(Sub-tasks) 관리

6. **달성률 피드백 & 3단 테마 모드**
   - 상단 헤더에 오늘 전체 할 일 중 완료 비율을 프로그레스 바로 표시
   - **3가지 테마 지원**: 화사한 **라이트 모드**, 눈이 편안한 웜그레이 톤의 **노말 모드**, 세련된 **다크 모드** (원클릭 순환 토글)

7. **Supabase 클라우드 데이터베이스 연동**
   - 실시간 클라우드 DB 연동으로 모바일, 태블릿, PC 어디서든 동일한 할 일 데이터 유지
   - 오프라인 상태나 통신 장애 시 로컬 스토리지 자동 백업 지원 (안정성 극대화)

8. **이메일/비밀번호 회원가입 & 사용자별 데이터 격리 (RLS)**
   - 비로그인 시 할 일 목록 차단 및 전용 로그인/회원가입 카드 화면 표시
   - 상단 헤더에 로그인한 사용자 이메일 표시 및 로그아웃 버튼 제공
   - Supabase RLS(Row Level Security) 정책을 통해 오직 본인이 작성한 할 일만 조회, 추가, 수정, 삭제 가능 (보안 완벽 보장)
